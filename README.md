# PromodeAgro Ecom Delivery SUI (Frontend UI)

This is the frontend UI for the PromodeAgro Ecom Delivery application. It provides the user interface for delivery operations, including order management, notifications, onboarding, and more.

## Features
- User authentication (Sign in, Sign out, OTP verification)
- Order management (Pending, Delivered, Undelivered)
- Notifications
- Profile management
- Onboarding process (Personal details, Bank details, Documents, Application status)

## Project Structure
- `src/` - Main source code directory
- `src/components/` - Reusable UI components
- `src/Views/` - Main views/pages
- `src/Redux-Store/` - Redux store and slices
- `src/Config/` - Configuration files
- `public/` - Static assets

## Getting Started

### Prerequisites
- Node.js (v14 or above recommended)
- npm or yarn

### Installation
1. Navigate to the project directory:
   ```bash
   cd promodeagro-ecom-delivery-sui
   ```
2. Install dependencies:
   ```bash
   npm install
   # or
   yarn install
   ```

### Running the App
To start the development server:
```bash
npm start
# or
yarn start
```

The app will be available at `http://localhost:3000` by default.

### Building for Production
To build the app for production:
```bash
npm run build
# or
yarn build
```
